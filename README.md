# Actividad 2: Diseño de un Recorrido Temático

## Grupo 8 - Evolución Espresso

Este repositorio público ha sido creado por el Grupo 8 para la Actividad 2 de la materia Diseño y Desarrollo Web.

### Objetivo
El propósito de este repositorio es presentar la propuesta de diseño para el sitio web **"Evolución Espresso"**, un recorrido temático por la evolución de la cultura del café en Buenos Aires.
